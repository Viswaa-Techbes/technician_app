BACKEND API INFORMATION:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Backend URL: https://technician-app.onrender.com

The Flutter app makes direct HTTP calls to your existing backend.
All user actions sync with the backend:

Authentication:
  ✓ POST /api/auth/login              - User login with credentials
  ✓ POST /api/auth/register           - New user registration
  ✓ POST /api/auth/logout             - User logout
  ✓ POST /api/auth/send-otp           - Send OTP for verification
  ✓ POST /api/auth/verify-otp         - Verify OTP token
  ✓ GET  /api/auth/session            - Check user session

Services:
  ✓ GET  /api/services                - Get all services
  ✓ GET  /api/services/{id}           - Get service details
  ✓ GET  /api/categories              - Get all categories
  ✓ GET  /api/services?search={q}     - Search services

Shopping Cart:
  ✓ GET  /api/v2/cart                 - Get current cart
  ✓ POST /api/v2/cart/add             - Add item to cart
  ✓ PUT  /api/v2/cart/{id}            - Update cart item
  ✓ DELETE /api/v2/cart/remove/{id}   - Remove from cart
  ✓ POST /api/v2/cart/clear           - Clear entire cart

Bookings:
  ✓ GET  /api/user/bookings           - Get user bookings
  ✓ GET  /api/bookings/{id}           - Get booking details
  ✓ POST /api/bookings/create         - Create new booking
  ✓ POST /api/bookings/{id}/cancel    - Cancel booking

User Management:
  ✓ GET  /api/v2/user/profile         - Get user profile
  ✓ PUT  /api/v2/user/profile         - Update profile
  ✓ GET  /api/v2/user/address         - Get addresses
  ✓ POST /api/v2/user/address         - Add address
  ✓ GET  /api/user/payments           - Get payment history

Reviews:
  ✓ POST /api/reviews                 - Submit review

1. INSTALL DEPENDENCIES:
   cd flutter_techbes_app
   flutter pub get

2. RUN THE APP:
   flutter run

3. TEST THE INTEGRATION:
   - Try logging in with a user from your backend
   - Services should load from /api/services
   - Add item to cart - syncs with /api/v2/cart
   - Create booking - syncs with /api/bookings/create
   - Dashboard shows real bookings from /api/user/bookings

4. VERIFY IN CONSOLE:
   You should see API calls like:
   [API] POST https://technician-app.onrender.com/api/auth/login
   [API] GET https://technician-app.onrender.com/api/services
   [API] POST https://technician-app.onrender.com/api/v2/cart/add
